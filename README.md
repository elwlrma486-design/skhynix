# SK hynix DART Financial Analysis

SK하이닉스(000660)의 DART 사업보고서 기반 연결 재무제표와 재무비율을 분석하는 프로젝트입니다.

## 기준
- 기준: 한국채택국제회계기준(K-IFRS), 연결 기준
- 기간: 2022~2025 회계연도
- 금액: 백만원
- 최신 연차보고서: 2025년 사업보고서, DART 접수번호 20260317000635
- 원문: https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260317000635

## 분석 프레임
첨부된 「재무제표 및 재무비율 실무 가이드」의 원칙을 적용했습니다.
1. 매출 성장
2. 이익률
3. 현금흐름과 FCF
4. 차입 부담 및 재무안정성
5. ROA/ROE 등 자본효율
6. 필요 시 시장가치 지표 확장

단일 비율보다 여러 지표의 연결을 우선하며, 손익계산서와 재무상태표의 기간/시점 차이를 고려해 ROA·ROE·총자산회전율에는 평균 자산·평균 자본을 사용합니다.

## 주요 파일
- data/financial_data.csv: DART 연결 재무 주요 수치
- analysis/financial_ratio_analysis.py: 재무비율 계산 코드
- reports/DART_report.md: DART 보고서 및 데이터 출처
- reports/financial_analysis.md: 추세 및 비율 분석 결과

## 주의
- 2023년은 영업손실/순손실이므로 전년 대비 이익 증가율은 일반적인 성장률 해석에 적합하지 않습니다.
- FCF는 가이드 정의에 따라 CFO - 현금 기준 CAPEX로 계산합니다.
- CAPEX는 연결 현금흐름표의 유형자산 취득 지출을 사용했습니다.
- 재무비율의 정의는 기관별로 다를 수 있으므로 본 프로젝트에서는 위 방법론을 명시적으로 고정합니다.
